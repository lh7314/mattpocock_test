这个工具不会做的事

  • 不会替你选一个 SKU 档位。4 SKU 与 5 SKU 无法区分时，两档都会完整计算并并列显示。
  • 不会把主表值和附表值加在一起：Certification 采用附表在本次 SKU 档位上的总量，并且只计入一次；主表单 SKU 数量与主表派生总量继续保留，只用于审计与差异分析。
  • 不会因为存在第二个 SSD / Memory Spec 就推断有第二波次；只有明确标为后续波次的 Spec 才被排除。
  • 不会做业务取整；443.8 就是 443.8。显示精度不会改动底层数值。
  • 不会在没有证据时扣减复用样机；只有已证明的额外确认复用才会扣减。
规则包与业务数值来自仓库内已验证的产物，前端不保存任何业务数字。 本工具为 MVP：无账号、无团队、无权限、无审批流。
